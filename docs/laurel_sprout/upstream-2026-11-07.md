## 3. The 10 most useful port items (ranked)

| # | Item | Where | Helps |
|---|---|---|---|
| 1 | **SGIs do not arrive on this GIC family; IPIs as software-pended SPIs.** tb128fu (SM6225, GIC at 0x0f200000 like ours): "SGIs written to ICC_SGI1R_EL1 never arrive here either (tb128fu-024/025: 8 self-IPIs sent, none taken), as on sheng's SM8550: IPIs are software-pended SPIs instead, one per core. This GIC has 544 INTIDs ... the IPIs are SPIs 504..511 = INTIDs 536..543" [V `UniXNU-tb128fu/board.toml:205-209`]. Also: XNU clears a core's `SIGPdisabled` only once that core has taken an IPI, so `armcpu-self-ipi=1` sends SGI 0 to itself from initCPU [V `board.toml:201-204`]. Our 26 catches show SGI 1 *pending* at the redistributor and never active [V watchdog.md 16]. A self-check of SGI delivery per core at boot, and a fallback to a per-core SPI (`GICD_ISPENDR` write) for `cpu_signal`, is one feature with a kill switch. Code: `ArmCpu-tb128fu/ArmCpu.cpp` (search `spi-ipi`), commit d9d3c333 "boot arguments for the virtual timer INTID and the SPI IPI base". | (a) |

## 5. Gotchas

- `gh search repos "two words"` is a phrase search over name/description and finds nothing; pass the words separately. The
  search API allows 30 calls a minute: sleep between calls or the batch returns HTTP 403.
- The `TABLE` of `get-references.sh` is one single-quoted string: comments and apostrophes go above `TABLE='`, never inside.
- `uefi-tb128fu` is a full Mu-Silicium copy (129 MB); the rest are small. `df -h` before: 135 GB free [V].
